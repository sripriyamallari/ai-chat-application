🤖 AI Chat Assistant

A Gemini-powered AI chat application built with Python, Streamlit, and Google Gemini API.

The application provides conversational AI with chat history, custom instructions, structured responses, model controls, automatic error handling, and token usage tracking.

✨ Features

- 🤖 Google Gemini API integration
- 💬 Conversational chat with history
- 🧠 Custom AI instructions
- 🌡️ Temperature control
- 🔢 Output token control
- 📦 Structured response mode
- 🔄 Automatic retry for temporary API errors
- 🛡️ Error handling
- 📊 Token usage tracking
- 🔐 Secure API key management with Streamlit Secrets

🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
- GitHub
- Streamlit Community Cloud

🔐 Security

The Gemini API key is stored securely using Streamlit Secrets and is not included in the source code.

GEMINI_API_KEY = "your_api_key_here"

📦 Installation

git clone YOUR_GITHUB_REPOSITORY_URL
cd ai-chat-application
pip install -r requirements.txt
streamlit run app.py
